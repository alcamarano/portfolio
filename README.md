## 📖 Sobre o projeto

Este portfólio foi desenvolvido para apresentar meus projetos, habilidades e trajetória na área de tecnologia. Sua estrutura prioriza performance, usabilidade e design responsivo (Mobile First), oferecendo uma experiência intuitiva e acessível em diferentes telas.


## ✨ Funcionalidades

- 📱 **Mobile First & Design Responsivo:** Adaptação fluida para dispositivos móveis, tablets e desktops.
- 🌓 **Modo Escuro / Claro (Dark/Light Mode):** Alternância dinâmica de temas para melhor acessibilidade visual.
- ✉️ **Formulário de Contato Funcional:** Integração para envio e recebimento de mensagens diretamente no e-mail, sem a necessidade de um backend próprio.
